Axelrod's model of cultural dissemination on networks

Each vertex carries a culture of F features with q values each. Neighbours interact at a rate proportional to the number of features they share, and an interaction copies one disagreeing feature. The dynamics stop when every edge is interior (all features shared) or boundary (nothing shared). The left view keeps the network fixed and colours vertices by culture; the right view shows the cultural domains as a quotient graph.

Model

Each edge is activated at rate one; one endpoint is chosen at random and, with probability equal to the fraction of shared features, copies one feature on which the two disagree (the continuous-time version of Lanchier, 2012). The simulation is exact: an active edge with overlap o is selected at rate o/F.

Results illustrated

In an absorbing state no triangle carries exactly one boundary edge, and the interior graph is a disjoint union of induced subgraphs (Lemma 4.1, Theorem 4.2), so ω(G_I) ≤ ω(G) (Corollary 4.3). A partition into connected blocks is a domain partition exactly when its quotient is properly q-colourable; each feature supplies such a colouring (Theorem 5.1), and the number of absorbing states is a sum of chromatic polynomials (Corollary 5.4). The feature, culture and domain assortativities share the interior fraction and satisfy r_f ≤ r_cult ≤ r_dom (Theorem 6.1). The total overlap Q is a submartingale, which bounds the expected absorption time (Theorem 3.2, Corollary 3.3).
